# Nam & Linh Wedding Site

Wedding website for Nam & Linh's celebration in Vietnam.

## RSVP responses

The RSVP form is prepared to save responses in Google Sheets through a bound
Google Apps Script. Follow [docs/google-sheets-rsvp.md](docs/google-sheets-rsvp.md)
to create the sheet endpoint and configure `VITE_RSVP_ENDPOINT` in Vercel.
